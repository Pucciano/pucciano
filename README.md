# Ante-Florian

> Evidence speaks, but only if you know how to make it talk.

I work in law enforcement, with a professional focus on digital forensics, forensic IT infrastructure and the analysis of complex digital evidence.

My work spans the acquisition, processing and examination of digital evidence from computer systems, mobile devices and networks, as well as the design of technical environments used for forensic analysis.

Alongside operational forensic work, I develop software, automation and AI-based systems for investigative and forensic use cases.

### AIVI

AIVI is my own LLM project developed exclusively for law-enforcement-related use cases.

Model	Purpose
aivi1.0-27B	Base model and foundation for further specialization
aivi1.0-27B-Cyber	Specialized model for digital forensics, cybersecurity and related technical domains

The objective of AIVI is not general-purpose conversational AI. The models are intended to support technical analysis, forensic workflows and the processing of structured and unstructured investigative data.
